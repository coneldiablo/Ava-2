# Серверный снимок AVA — 28 октября 2026

Этот каталог фиксирует код работающих CRM, provisioning worker, голосового движка и admin backend. Полная сверка выполнена чтением контейнеров 28 октября; сервер не изменялся.

Корень репозитория содержит последний объединённый в рабочей ветке исходный код. В production компоненты выпускались отдельно: поэтому worker и часть Onyx-файлов движка имеют другие версии. Они сохранены в `overlays/`, а `manifest.json` указывает точный источник каждого файла и SHA-256. Это позволяет получить фактическое дерево конкретного сервиса, не выдавая одну версию за все четыре.

```bash
python3 deploy/production-snapshot-20261028/source_snapshot.py verify
python3 deploy/production-snapshot-20261028/source_snapshot.py materialize --service all --output /tmp/ava-runtime-source
```

`verify` проверяет 633 файла четырёх сервисов. `materialize` создаёт новый каталог с исходниками, проверяет хеши результата и не обращается к серверу. Каталог назначения должен быть пустым и находиться вне репозитория. Он содержит исходники, а не готовые контейнеры: зависимости, frontend build, секреты, данные и конфигурация окружения поставляются отдельно.

Для внешнего WhatsApp gateway сохранены image ID, хеши пяти изменённых файлов, upstream fixtures и пути двух patch-рецептов. Сторонние зависимости и их лицензии не заменяются лицензией AVA. Прямое воспроизведение полного gateway image требует его upstream build context.

`config-templates/` содержит обезличенные примеры текущих настроек движка. Они не являются production `.env`; значения окружения, ключи, пароли, SSH-конфигурация и клиентские данные сюда не входят. Оригинальные runtime config hashes оставлены только для установления версии.

Этот снимок подтверждает версии кода. Он не утверждает, что все пользовательские сценарии исправны: остаются вопросы памяти Sales Brains, запуска кампаний и доступа Avito Messenger API. Исторический полный набор тестов также имеет известные ошибки; результаты отдельных проверок нельзя считать зелёным общим CI.
